# AGENTS.md — Flutter-Frontend

Gilt für `Automation_App_Frontend/` zusätzlich zur Wurzel-`AGENTS.md`.

Vor jeder Änderung in diesem Teilbaum `Automation_App_Frontend/CLAUDE.md` vollständig lesen und
als verbindliches Frontend-Handbuch anwenden. Vor der Arbeit an einem Feature außerdem dessen
`lib/features/<feature>/FEATURE.md` lesen; bei einer featureübergreifenden Datenkette zusätzlich
`../docs/DATENFLUESSE.md`.

Das gepinnte Flutter-SDK verwenden, wenn es lokal verfügbar ist. Generierte Dart-Dateien nie von
Hand ändern. Geänderte Dart-Dateien zeitnah formatieren und zunächst den kleinsten aussagekräftigen
Test aus dem Paketstamm ausführen; den vollständigen Prüfumfang bestimmt die Wurzel-`AGENTS.md`.
